# Relatórios

Saídas geradas pelos agentes e rotinas. Padrão de nome: `AAAA-MM-DD-<tipo>-<area>.md`

- `*-briefing.md` — briefing diário (`/briefing`)
- `*-semanal.md` — reunião semanal (`/reuniao-semanal`)
- `AAAA-MM-fechamento-mensal.md` — fechamento do mês (`/fechamento-mensal`)
- `*-diagnostico-<tema>.md` — diagnósticos (`/diagnostico`)
- `*-plano-captacao-<unidade>.md` — planos de captação (`/plano-captacao`)
- `*-radar.md` — radar da Sentinela

Relatórios antigos são a memória do negócio: o Estrategista os lê para ver tendências.
